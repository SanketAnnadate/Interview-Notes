# What is React.js?

> [!INFO] Definition
> **React.js** is an open-source **JavaScript library** developed for building **user interfaces (UI)**, particularly **Single Page Applications (SPAs)**.

---

## Key Points

- **Open Source** → Source code is publicly available and can be modified by anyone.
- **JavaScript Library** → React focuses only on building the **View (UI)** layer of an application.
- **Developed By** → Meta (formerly Facebook).
- **Primary Purpose** → Build fast, interactive, and reusable user interfaces.
- **Main Use Case** → Single Page Applications (SPAs).

---
### Single Page Application (SPA)
In a Single Page Application:
- The browser loads **one HTML page**.
- React updates only the required parts of the page without reloading the entire website.
- This results in a faster and smoother user experience.

---

## Scenario-Based Question

### Scenario
Your banking application should update only the account balance after a transaction without refreshing the entire page.

**Why is React suitable?**

**Answer:**
React updates only the affected component using the Virtual DOM and reconciliation process, resulting in faster rendering and a better user experience.
