greetings covered in the lesson

| German Greeting           | English Meaning    | Usage Context                        |
| :------------------------ | :----------------- | :----------------------------------- |
| **Hallo**                 | Hello              | Informal (most common)               |
| **Guten Tag**             | Good day           | Formal (any time of day)             |
| **Guten Morgen**          | Good morning       | Formal/Polite (morning)              |
| **Guten Abend**           | Good evening       | Formal/Polite (evening)              |
| **Gute Nacht**            | Good night         | Before bed                           |
| **Grüß Gott**             | God greet you      | Regional (Austria/Bavaria)           |
| **Grüß dich / Grüß euch** | Greet you          | Casual/Regional                      |
| **Servus**                | Hello / Goodbye    | Informal (South Germany/Switzerland) |
| **Tschüss**               | Bye                | Informal (all over Germany)          |
| **Ciao**                  | Bye / Hello        | Informal (common in Europe)          |
| **Auf Wiedersehen**       | Goodbye (formal)   | Formal farewell                      |
| **Auf Wiederhören**       | Goodbye (on phone) | Formal (phone calls)                 |
| **Bis bald**              | See you soon       | Informal (friends)                   |
